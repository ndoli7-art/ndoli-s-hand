# Ndoli's Hand 🖐️

**Ndoli's Hand** is an interactive Socratic tutoring application designed to assist students in breaking down quantitative and technical coursework into guided, step-by-step solutions.

## Features
- **Socratic Decomposition:** Converts homework problems into guided checkpoints.
- **Multi-Level Hints:** Tiered hints ranging from conceptual principles to specific formulas.
- **Multi-Subject Support:** Tailored assistance for Statistics, Programming, Logic, and Databases.
